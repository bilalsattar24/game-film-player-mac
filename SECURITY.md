# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| `main` branch | ✅ |

## Reporting a vulnerability

If you discover a security issue, please **do not** open a public GitHub issue.

Instead, open a [private security advisory](https://github.com/bilalsattar24/game-film-player-mac/security/advisories/new) on GitHub, or contact the maintainer directly.

We will acknowledge receipt and work on a fix as quickly as possible.

## Scope

Game Film Player is a local, sandboxed macOS app that plays user-selected video files. It does not collect analytics, transmit data over the network, or store credentials.
